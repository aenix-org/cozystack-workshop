## 10. सामग्री पहले से ही bastion पर है

**क्लोन करने के लिए कुछ नहीं**

📍 **कहाँ:** उसी bastion पर जहाँ आप अभी-अभी SSH से लॉगिन हुए हैं।

सामग्री वाला फ़ोल्डर पहले से ही आपकी होम डायरेक्टरी में मौजूद है, और **आपका टेनेंट नंबर उसमें पहले से भरा हुआ है**। `tenant-workshopXX` प्लेसहोल्डर bastion तैयार करते समय आपके `tenant-workshopNN` से बदल दिए गए थे — ढूँढ़कर बदलने जैसा कुछ नहीं करना है, फ़ाइलों को जैसी हैं वैसे ही लागू कर दें।

फ़ोल्डर में जाइए और देखिए अंदर क्या है:

```bash
cd ~/workshop
ls manifests scripts
```

आपको चार मैनिफ़ेस्ट और चार स्क्रिप्ट दिखने चाहिए — ठीक वही, जो फ़ाइल-मैप में थे। पक्का कर लीजिए कि जो नंबर भरा है वह आपका ही है:

```bash
grep -m1 namespace manifests/01-bucket.yaml
```

`namespace:` वाली पंक्ति में आपका `tenant-workshopNN` होगा, `tenant-workshopXX` नहीं।

**अगर भटक जाएँ**, तो वापस लौटने का रास्ता हमेशा एक ही है:
```bash
cd ~/workshop
```

**संपादन के लिए फ़ाइलें किससे खोलें।** इसकी ज़रूरत ठीक एक बार पड़ेगी — तीसरे चरण में `manifests/03-app-vm.yaml` में presigned URL चिपकाने के लिए। `nano` से काम चल जाएगा:
`nano manifests/03-app-vm.yaml` (सहेजें: `Ctrl+O`, `Enter`, बाहर निकलें: `Ctrl+X`)।

एकमात्र प्लेसहोल्डर जो जानबूझकर छोड़ा गया है, वह `manifests/03-app-vm.yaml` में है, पंक्ति
`url: "ВСТАВЬТЕ_PRESIGNED_URL"`। यह URL आपको तब मिलेगा जब आप इमेज कन्वर्ट करेंगे। फ़िलहाल बस इतना जान लीजिए कि वह वहाँ आपका इंतज़ार कर रहा है।
