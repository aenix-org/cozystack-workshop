## 3. はじめる前に: 必要なもの

**準備をしましょう**

お手元のノートPCにインストールするものは何もありません。作業はすべて共有の **bastion** 上で行います。この bastion には
`kubectl`、`virtctl`、`git` がすでにインストールされており、あなたのテナントへのアクセスも設定済みです。

必要なのは SSH クライアントだけで、これはどのシステムにも備わっています。

• **macOS / Linux** — ターミナルがすでに `ssh` を扱えるので、何もインストールする必要はありません。
• **Windows** — PowerShell に組み込みの `ssh` で十分ですし、PuTTY / Windows Terminal でも構いません。

ログイン名、パスワード、そして bastion のアドレスは講師がお渡しします。次のメッセージで、ログインの方法を説明します。
