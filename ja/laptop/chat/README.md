# ワークショップのチャットメッセージ

1ファイルにつき1メッセージです。まとめてではなく、実習の進行に合わせて投稿してください。そうしないと、参加者が先に進みすぎて、まだなぜそれが必要なのかを説明していないところで行き詰まってしまいます。

`workshopXX` と書かれているところはすべて、参加者が自分の番号を入れます。`workshop03`、`workshop07` などです。番号はパスワードとともに、一人ひとりに個別に配られます。
