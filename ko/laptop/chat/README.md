# 워크숍 채팅 메시지

한 파일이 하나의 메시지입니다. 한꺼번에 올리지 말고, 실습이 진행되는 흐름에 맞춰 올리세요. 그러지 않으면
참가자들이 앞서 달려나가, 왜 그것이 필요한지 아직 설명하지 않은 지점에서 막혀버립니다.

`workshopXX`가 나오는 곳마다 참가자는 자신의 번호를 채워 넣습니다: `workshop03`,
`workshop07` 등입니다. 번호는 비밀번호와 함께 각자에게 개별적으로 발급됩니다.

각 파일은 Telegram의 한도인 4096자 안에 들어갑니다.
