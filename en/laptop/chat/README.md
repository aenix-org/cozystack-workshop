# Workshop chat messages

One file, one message. Post them as the hands-on work goes along, not all at once: otherwise
participants will run ahead and get stuck somewhere you haven't yet explained why it's needed.

Everywhere you see `workshopXX`, the participant fills in their own number: `workshop03`,
`workshop07`, and so on. The number is handed out to each person individually, along with a password.

Each file fits within Telegram's limit — 4096 characters.
