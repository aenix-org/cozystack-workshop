## 17. Розбір: що робить convert.sh

Скрипт складається з п'яти кроків, і кожен друкує, чим зайнятий.

**Крок 1 — перевірка апаратного прискорення.** Дивиться, чи є пристрій `/dev/kvm`.
`virt-v2v` всередині себе запускає маленьку віртуальну машину, щоб залізти в образ, —
і якщо процесор пробрасується всередину нашої машини, ця вкладена віртуалізація йде
швидко. Якщо ні — вмикається програмний режим: повільніше, але працює. Рядок
`LIBGUESTFS_BACKEND=direct` — це якраз перемикання в такий режим.

**Крок 2 — завантаження вихідного образу.**

```bash
wget -O source.ova "$OVA_URL"
```

Тягне `app-1.ova` зі спільного сховища воркшопу — того самого, що на карті вище. Викладач
залив туди файл заздалегідь. **У своєму проєкті на цьому місці було б вивантаження з vSphere:**
`Export OVF Template` або `ovftool`, а далі те саме перепакування.

**Крок 3 — саме перепакування.**

```bash
virt-v2v -i ova /root/source.ova -o local -os /root/out -of qcow2 -on app
```

`-i ova` — що на вході: файл формату OVA. `-o local -os /root/out` — куди скласти
результат: у локальну теку `/root/out`. `-of qcow2` — **обов'язковий** прапорець: без нього
`virt-v2v` вибере формат за замовчуванням, і платформа такий диск не прийме. `-on app` —
як назвати результат, звідси візьметься ім'я файлу `app.qcow2`.

Іти це буде хвилини — на екрані побіжать рядки на кшталт `Copying disk 1/1`. Саме
тут і відбувається та друга, невидима робота з драйверами, про яку сказано вище.

**Крок 4 — вивантаження у ваш бакет.**

```bash
mc alias set mybucket "$S3_ENDPOINT" "$ACCESS_KEY" "$SECRET_KEY"
mc cp /root/out/app.qcow2 "mybucket/$BUCKET/app.qcow2"
```

`mc alias set` запам'ятовує адресу сховища та ключі під коротким іменем `mybucket`, щоб
далі не повторювати їх у кожній команді. `mc cp` копіює файл — синтаксис навмисне
такий самий, як у звичайного `cp`.

**Крок 5 — посилання для платформи.**

```bash
mc share download --expire 168h "mybucket/$BUCKET/app.qcow2"
```

Створює тимчасове підписане посилання на сім днів (168 годин). Підписане — означає,
що всередину адреси вшитий криптографічний підпис, і за цим посиланням файл завантажить будь-хто,
але тільки за ним і тільки поки воно живе. Відкривати бакет усьому світові не потрібно, і ключі
доступу платформі передавати теж не потрібно.

Посилання шукайте у виводі після слова `Share:` — воно знадобиться на наступній фазі.
