## 18. Крок 3: конвертація образу

**Перетворюємо образ VMware на образ для KVM**

📍 **Де:** усередині машини-конвертера, куди ви щойно зайшли через консоль. Не на
ноутбуці.

📄 Працюємо зі `scripts/convert.sh`. Ця машина має доступ до мережі, тому вона завантажить
файл сама — копіювати через буфер обміну не потрібно.

Забираємо скрипт з GitHub прямо в машину:
```bash
curl -fsSLO https://raw.githubusercontent.com/aenix-org/cozystack-migration-workshop/master/laptop/scripts/convert.sh
```

Відкриваємо його:
```bash
nano convert.sh
```

**Ось і згодилися три значення, які ви записали в блокнот на кроці 1.** На початку
файлу є блок «ВСТАВТЕ СВОЇ ЗНАЧЕННЯ» — замініть у ньому заглушки на свої, залишивши
лапки на місці:

```
BUCKET="your-bucket-name"
ACCESS_KEY="your-accessKey"
SECRET_KEY="your-secretKey"
```

Рядок `S3_ENDPOINT` і посилання на початковий образ не чіпайте — вони вже правильні
й однакові в усіх.

Зберегти в nano: `Ctrl+O`, потім `Enter`, потім `Ctrl+X` для виходу. Перевірити, що
заглушок не залишилося:
```bash
grep ВСТАВЬТЕ convert.sh || echo "all filled in, ready to run"
```

Запускаємо — обов'язково через `sudo`, скрипту потрібні права root:
```bash
sudo bash convert.sh
```

Що відбувається всередині: скрипт завантажує початковий образ, запускає `virt-v2v`,
стискає результат і заливає його у ваш бакет.

Найважливіше робить `virt-v2v`. Він змінює не лише формат файлу: він підкладає
всередину гостьової системи драйвери virtio і виправляє завантажувач. Без цього машина
на новому гіпервізорі не стартує взагалі.

⏳ **Це займе близько п'яти хвилин.** На нашому тестовому середовищі немає вкладеної віртуалізації,
тому конвертація йде в режимі емуляції. Прогрес видно в консолі — не закривайте її.

Наприкінці скрипт надрукує **presigned-посилання** на ваш образ — шукайте у виводі рядок,
що починається зі слова `Share:`, посилання йде одразу за ним.

**Що з ним робити:** скопіюйте його в той самий блокнот. На наступному кроці ви повернетеся
на ноутбук, відкриєте `manifests/03-app-vm.yaml` і вставите його в поле `url` — туди, де
зараз стоїть заглушка `ВСТАВЬТЕ_PRESIGNED_URL`. Та сама, про яку я попереджав,
коли ми підставляли номери.

Це тимчасове підписане посилання: сховище назовні не відкрите, а посилання ви зробили
своїми ж ключами. Воно живе тиждень — на воркшоп і на експерименти після вистачить
із запасом.
