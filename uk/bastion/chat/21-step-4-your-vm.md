## 21. Крок 4: ваша віртуальна машина

**Піднімаємо машину з власного образу**

📍 **Де:** на бастіоні.

⚠️ **Спершу вимкніть машину-конвертер** — вона своє відпрацювала і тримає 8Gi вашої квоти.
Якщо її не прибрати, нова машина повисне в `Pending`, і виглядатиме це
як поломка тестового середовища. На минулих воркшопах на цьому застрягли майже всі:

```bash
kubectl delete vminstance convert --namespace tenant-workshopXX
kubectl delete vmdisk convert-tools --namespace tenant-workshopXX
```

Образ у бакеті при цьому залишається — з нього й піднімемося.

Тепер відкрийте `manifests/03-app-vm.yaml`, вставте presigned-посилання у поле `url`
і застосуйте:

```bash
kubectl apply -f manifests/03-app-vm.yaml
kubectl get vminstance -n tenant-workshopXX -w
```

Спершу кластер завантажить образ за посиланням і розкладе його по репліках — це займе хвилину-дві.
Потім машина запуститься.

Заходимо всередину:
```bash
virtctl console --namespace=tenant-workshopXX vm-instance-app-1
```

**Доступ до вашої машини:**
```
login:    root
password: cozydemo
```

Щоб вийти з консолі — `Ctrl+]`.

**Тут та сама пара об'єктів, що й з машиною-конвертером**, тільки диск береться
не з каталогу, а завантажується за вашим посиланням:

• **VM Disk** `app-1` — 10Gi, source = http, той самий presigned-URL
• **VM Instance** `app-1` — профіль `centos.7`, instance type `u1.medium`

Імена збігаються, і це нормально: диск і машина — різні типи об'єктів. У командах
`virtctl` машина, як і минулого разу, зветься з префіксом: **`vm-instance-app-1`**.

🖱 **Через дашборд:** **1)** **VM Disk → Deploy new**: ім'я `app-1`, source = **http**,
у полі URL — presigned-посилання, розмір `10Gi`, storage class `replicated`.
**2)** **VM Instance → Deploy new**: ім'я `app-1`, instance type `u1.medium`,
profile `centos.7`, диск — `app-1`. Консоль — кнопка **VNC** на сторінці машини.

Зверніть увагу, що ви щойно зробили: описали віртуальну машину текстом
і застосували його однією командою. Цей файл можна покласти в репозиторій і підняти
сотню таких самих машин, не зробивши жодного кліку.
