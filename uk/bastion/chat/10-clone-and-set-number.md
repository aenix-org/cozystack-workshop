## 10. Матеріали вже на бастіоні

**Клонувати нічого не потрібно**

📍 **Де:** на бастіоні, куди ви щойно зайшли по SSH.

Тека з матеріалами вже лежить у вашій домашній директорії, і **ваш номер тенанта в ній уже підставлено**. Заглушки `tenant-workshopXX` замінено на ваш `tenant-workshopNN` під час підготовки бастіона — шукати й замінювати нічого не треба, одразу застосовуйте файли як є.

Заходимо в теку й дивимось, що всередині:

```bash
cd ~/workshop
ls manifests scripts
```

Маєте побачити чотири маніфести й чотири скрипти — ті самі, з карти файлів. Переконайтеся, що підставлено саме ваш номер:

```bash
grep -m1 namespace manifests/01-bucket.yaml
```

У рядку `namespace:` буде ваш `tenant-workshopNN`, а не `tenant-workshopXX`.

**Якщо загубилися**, повернутися завжди однаково:
```bash
cd ~/workshop
```

**Чим відкривати файли для правки.** Знадобиться рівно один раз — щоб вписати presigned-посилання в `manifests/03-app-vm.yaml` на третій фазі. Згодиться `nano`:
`nano manifests/03-app-vm.yaml` (зберегти: `Ctrl+O`, `Enter`, вийти: `Ctrl+X`).

Єдина заглушка, яку залишено навмисно, — у `manifests/03-app-vm.yaml`, рядок
`url: "ВСТАВЬТЕ_PRESIGNED_URL"`. Це посилання ви отримаєте, коли сконвертуєте образ. Наразі просто знайте, що воно на вас там чекає.
