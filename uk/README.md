# Міграція з VMware на Cozystack: воркшоп і лабораторні

Матеріали для тих, хто адмініструє VMware і хоче зрозуміти, що таке Cozystack —
не за презентацією, а руками. Kubernetes знати не потрібно: усе пояснюється по ходу, через
те, що ви вже знаєте з vSphere.

## Два шляхи проходження — виберіть свій

Один і той самий воркшоп зібрано у двох варіантах. Відрізняються вони лише тим, **звідки ви
працюєте з кластером**. Викладач скаже, який ваш.

| | [`laptop/`](laptop/) — зі свого ноутбука | [`bastion/`](bastion/) — через бастіон |
|---|---|---|
| **Інструменти** | ставите самі: `kubectl`, `virtctl`, `kubelogin` | уже стоять на бастіоні |
| **Доступ до кластера** | kubeconfig з дашборда, вхід через браузер | заходите по SSH, доступ уже налаштовано |
| **Номер тенанта у файлах** | підставляєте самі | підставлено заздалегідь |
| **Перевірка застосунку** | `virtctl port-forward` + `localhost:8080` | за доменним іменем `app.<номер>.workshop.aenix.io` |
| **Кому** | у кого немає спільного бастіона | підготовлене тестове середовище з бастіоном |

Усередині кожної теки — самодостатній набір: свій `README.md` (маршрут), `chat/`
(повідомлення для чату по кроках), `manifests/`, `scripts/`. Відкривайте README свого шляху
й ідіть за ним.

## Лабораторні

В обох теках лежить `labs/` — шістнадцять самостійних лабораторних, які
проходяться у своєму темпі, вдома або в перервах. Кожна зі своїм скриптом перевірки
(`check/`). Увесь набір — близько дев'яти годин, не на один присід: беріть по одній за вечір.

| Лаба | Про що | Час |
|---|---|---|
| 0 · Свій кластер | завести собі Kubernetes за десять хвилин | 15 хв |
| 1 · Перший застосунок | розгорнути застосунок одним файлом і однією командою | 25 хв |
| 2 · Самовідновлення | видалити копію й подивитися, що буде | 25 хв |
| 3 · Масштабування | дати навантаження й побачити, як ростуть копії | 30 хв |
| 4 · Викочування й відкат | змінити версію під навантаженням, без простою | 30 хв |
| 5 · Інфраструктура в Git | описати все в репозиторії й котити через push | 40 хв |
| 6 · Свій реєстр | Harbor, збірка сервісу на Go, деплой зі свого реєстру | 45 хв |
| 7 · Кеш | Redis перед повільним бекендом, виграш у цифрах | 50 хв |
| 8 · Секрети | прибрати пароль з маніфесту в OpenBao | 50 хв |
| 9 · Аналітика | мільйон рядків і звіт за мілісекунди | 45 хв |
| 10 · Документи | MongoDB там, де записи мають різну форму | 45 хв |
| 11 · Збірка мобільного | зібрати APK у кластері, покласти в бакет | 40 хв |
| 12 · Віртуалка поруч | легасі не треба контейнеризувати, щоб переїхати | 30 хв |
| 13 · Своє в каталозі | запакувати застосунок як аппку Cozystack | 40 хв |
| 14 · Спостережуваність | знайти в графіках сліди свого ж навантаження | 30 хв |
| 15 · Що робити в понеділок | з якої системи почати і що обіцяти керівництву | 20 хв |

Посилання на лаби — у README вашого шляху: [`laptop/labs/`](laptop/labs/) або
[`bastion/labs/`](bastion/labs/).
