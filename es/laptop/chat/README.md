# Mensajes para el chat del taller

Un archivo, un mensaje. Publícalos a medida que avanza la práctica, no todos de golpe: de lo contrario
los participantes se adelantarán y se quedarán atascados en algún punto donde todavía no has explicado por qué hace falta.

En todos los sitios donde veas `workshopXX`, el participante rellena su propio número: `workshop03`,
`workshop07`, y así sucesivamente. El número se le entrega a cada persona individualmente, junto con una contraseña.

Cada archivo cabe dentro del límite de Telegram — 4096 caracteres.
