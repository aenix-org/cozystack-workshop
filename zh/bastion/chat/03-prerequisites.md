## 3. 开始之前：你需要准备什么

**做好准备**

你的笔记本上不用安装任何东西。所有操作都在一台共享的 **bastion（跳板机）** 上进行——上面已经装好了
`kubectl`、`virtctl` 和 `git`，到你租户的访问也已经配置妥当。

你唯一需要的是一个 SSH 客户端，任何系统都自带它：

• **macOS / Linux** —— 终端本身就支持 `ssh`，无需安装任何东西。
• **Windows** —— PowerShell 里内置的 `ssh` 就够用，或者用 PuTTY / Windows Terminal。

讲师会给你一个登录名、一个密码和 bastion 的地址。下一条消息里——讲如何登录。
